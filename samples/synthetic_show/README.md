# Synthetic show: "The Locket" (fictional)

Three short episodes we wrote ourselves, in the same file format as a real script pack. Tests, demos and prompt examples use these, never the confidential pack.

Edge cases on purpose:
- Ep 1: two-line ACTION text; `(O.S.)` speaker; a flag inside the emotion parens (`VERA (Startled, O.S.)`); a character first credited by description (`THE STRANGER`), later by name (`ELLIS`).
- Ep 2: capitalised `SCENE HEADING:` / `SCENE START:` / `SCENE END:`; a scene with no SOUND FX; `(V.O.)`; `SPEAKER (O.S.) (Emotion)`.
- Ep 3: reproduces the worked example in `docs/PROCESS_GUIDE.md` Processes 1–3 (`E03-B010`, `E03-B011`, `E03-B029`–`E03-B031`). Blocks are not strictly time-ordered (a dialogue line before the camera shot it sits under), as in real packs.

Block counts: ep 1 = 20 (8 CAMERA, 3 ACTION, 2 SOUND FX, 7 dialogue); ep 2 = 13 (6, 2, 1, 4); ep 3 = 41 (18, 5, 5, 13).
